AI Coding 产品设计作业 · 周末城市探索指南

这个周末，别再问「去哪玩」。

溜达 LIUDA —— 面向大学生的周末探索 App。它把你所在城市的展览、市集、演出、City Walk、短途徒步， 按你的偏好 × 天气 × 预算 × 同行人数实时拼成一份「本周末专属行程」；一键组队出发，打卡点亮城市足迹，攻略沉淀成社区。

🎯 目标用户 18–26 岁大学生 / 年轻职场人 🧭 核心场景 周五晚决定 · 周六出发 📱 形态 移动端 App（小程序冷启动）
01 · User Pain Points

为什么「决定去哪」比「去玩」更累？

我们调研了身边同学的周末决策过程，发现从「想出门」到「出门」平均要经历 5+ 个 App、2–3 小时的信息搬运，而且经常在最后一步放弃。

01
信息分散

活动信息「散装」在各平台

展览在小红书、livehouse 在秀动、市集在公众号、天气在天气 App——没有一处能横向对比「这周末到底有什么」。

城市活动聚合 Feed，按周末时间轴统一排列
02
决策成本高

天气 / 预算 / 人数，变量太多

查好一个市集，结果周六下雨；约好 4 个人，人均预算对不上。每个变量变化一次，计划就要推翻重来。

四维智能匹配引擎：偏好 × 天气 × 预算 × 人数
03
找不到搭子

「一个人懒得去」是最大劝退项

想看展的朋友不感兴趣，感兴趣的朋友没时间。社恐 + 搭子难匹配，导致大量计划直接夭折在微信群里。

兴趣标签组队系统：i 人友好 / 摄影党 / 佛系逛
02 · Product Structure

产品结构：一条主线 + 四个模块

以「周末行程」为主线串联全部功能：推荐 → 决策 → 组队 → 出发 → 打卡 → 分享，形成完整闭环。

🚶 主线闭环：收到推荐 → 生成行程 → 组队出发 → 现场打卡 → 输出攻略 → 反哺推荐（个性化数据沉淀）

🧭探索（首页）

  • 周末时间轴活动聚合 Feed
  • 四维筛选：类别 / 天气 / 预算 / 人数
  • 「本周为你挑」AI 推荐卡
  • 天气突变自动换案（Plan B）

🤝组队出发

  • 按活动找搭子（兴趣标签匹配）
  • 发起新队 / 拼入已有队
  • 队内行程协作 + 集合点导航
  • 安全机制：学生认证 / 信用分

📍打卡足迹

  • 活动地点一键打卡（照片 + 感受）
  • 城市足迹地图：点亮探索过的街区
  • 探索等级 + 限定徽章体系
  • 周末报告：自动生成回忆卡片

📖攻略社区

  • 打卡内容一键转攻略
  • 结构化攻略模板（路线 / 花费 / 避雷）
  • 同城攻略榜 & 好友动态
  • 攻略直接「一键复刻」为我的行程

🪪我的

  • 偏好画像（可调权重：省钱 / 出片 / 社交）
  • 我的队伍 & 历史行程
  • 徽章墙 & 探索等级
  • 校园身份认证
03 · Key Features

五个让年轻人愿意留下来的功能

🌦️

WEATHER-AWARE天气感知推荐

接入实时天气：晴天优先户外市集与徒步线，雨天自动切到室内展和 livehouse；周五晚推送「周六有雨，Plan B 已备好」。

💸

BUDGET MODE预算滑杆

一根滑杆从 ¥0 拉到 ¥300：免费展、拼车徒步、平价市集自动重排优先级，人均花费提前算清，拒绝「到了才发现超预算」。

🤝

SQUAD UP搭子匹配组队

按「i人友好 / 摄影党 / 佛系逛 / 特种兵」等标签找搭子；4 人小队上限控制社交压力，队内轻协作：集合点、AA 记账、行程提醒。

📍

CITY MAP足迹点亮地图

每打卡一个地点，城市地图上就点亮一片街区。探索等级从「新市民」到「城市显眼包」，晒图欲和收集欲同时拉满。

📖

UGC LOOP攻略一键复刻

别人的攻略不是看完就走：一键把攻略里的路线、花费、排队时间复刻成自己的周末行程，UGC 直接转化为行程转化率。

04 · UI Prototype

前端原型：深夜霓虹 × 软萌反差

深色底 + 电光渐变（粉 → 紫 → 薄荷），大圆角卡片、胶囊标签、玻璃拟态浮层——「夜跑完打开也不刺眼」的时尚感，同时保持信息密度克制。

05 · Why Us

差异化与冷启动思路

DIFF 01

不做到家 App，只做周末决策

不做「又一个本地生活平台」，而是专注周五到周日的「决策时刻」。小切口、高频次、强场景，避开与大众点评 / 小红书的正面竞争。

DIFF 02

推荐可解释，越用越懂你

每张推荐卡都写清「为什么推给你」（天气 / 预算 / 偏好），用户可反馈「不像我」；打卡与攻略行为反哺推荐，形成数据飞轮。

DIFF 03

搭子社交，轻而不重

组队是「一次性轻社交」：活动结束即散，不沉淀陌生人关系链，规避校园社交产品的信任与安全压力，学生认证 + 信用分兜底。

COLD START

冷启动：从 5 所高校开始

先做微信小程序验证（成本低、易裂变），在 5 所高校发展「校园探索官」，官方组 50 条精品周末路线作为初始 PGC 内容，再扩城市。
